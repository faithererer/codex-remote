# 真机验收清单

交付前测试记录按“单元测试”“单 PC 双身份接口联调”“Android 真机”“两台物理 PC”分别标注，不能相互替代。

## 第二台真实 Windows PC

1. 两台电脑各自运行一个原 Codex 桌面和桥接，并分别配对同一手机。
2. 分别让两个原会话运行任务；手机“全部关注”同时看见进度。
3. 给 A 追加指示，给 B 发送另一条指令；确认原电脑各自收到，模型、工具、目录、账号不变。
4. 同名会话，或使用隔离测试环境中的相同会话 ID，验证发送、中断、审批和通知目的地都按电脑身份区分。
5. 断开 A，确认 B 继续运行；A 的草稿不自动发给 B。
6. A 重启后端后，旧 instanceId 的操作与审批必须拒绝。
7. 在发送时断网，确认手机不自动重发；通过会话和 operationId 核对。

## 权限与手机系统

1. 在本来会触发审批的现有任务里分别从桌面与手机响应，另一端显示已解决；未知工具在手机不能批准。
2. 核对桌面工具仍正常，沙箱、审批、模型设置未因接入更改。
3. 未配对、已过期二维码、复用二维码、错误证书、撤销凭证必须拒绝；另一台电脑的凭证不能授权本机。
4. 手机移动网络和 Wi-Fi 切换、锁屏、系统省电策略、Tailscale 断线重连；完成／失败／待输入／持续断连通知明确来源且锁屏不显示正文。
5. 停止前台监控、强停 App、重新打开；必须停止或补齐状态，不承诺强停期间实时通知。

未经第二台物理 PC 及这些实测，不标记整个产品已经完成多电脑验收。

## 0.1.5 局域网验收

1. 两端更新到 0.1.5，手机关闭 Tailscale、保持同一 Wi-Fi／局域网；电脑选择局域网二维码，扫码并在电脑确认，核对实时会话和执行结果。
2. 已通过 Tailscale 配对的电脑，在手机“修改连接地址”切为局域网；核对原证书／电脑身份、关注、草稿、未读标记和未确认操作保留。另一台电脑的连接不受影响。
3. 错误证书、另一台电脑、撤销的凭证、公网 IP、HTTP、主机名及伪造转发头不能建立新信任；失败不保存地址。
4. 两种网络入口核对同一 hostId／instanceId，同 operationId 的相同请求返回同一记录，不同内容拒绝。地址切换、断线或旧连接迟到事件不导致重复执行或串线。
5. 更换 Wi-Fi／DHCP 后，电脑自动重新检测具体私网监听地址，不改绑通配或公网；手机手动更新地址后核对原身份。网卡变化不重启 Codex。
6. 测试防火墙拒绝、路由器访客网络／客户端隔离、VPN 接管局域网、锁屏及后台恢复。不能把同 PC 自连结果当作手机防火墙穿透测试。

## 0.1.3 专项验收

1. 原始输入先到、原生回显后到时只保留一条且显示 ID 不变；真正再次发送同文、不同轮次、不同客户端 ID、追加指示仍各自保留。
2. 同一帧连续点击发送、新建和 Fork，不产生第二个意图；同机另一个操作提交中时不排队。A 提交不阻塞 B；异常／取消后锁可释放，未知结果仍不能自动重试。
3. 在用户明确用于验收的空闲会话中选择当前工作区 Fork，确认复制历史、子会话独立但共用文件，没有自动新指令或停止父任务。
4. Git 仓库中选择新工作树，确认使用当前工作区状态、等待异步设置并从任务列表打开真实子会话；非 Git 目录不能点击此项，临时 clientThreadId 不能控制聊天。
5. 原会话运行中、审批未解决、实例改变或用户确认时已进入另一轮，应拒绝旧 Fork；历史设置未同步完成时提示核对，不自动发送或再次 Fork。
6. Fork 点击后断网或桥接重启，按 operationId 核对原结果，不再次创建；两个电脑的同标题／同会话 ID 不能让来源、结果提示或子会话导航串线。

当前已完成单元／接口及真实快照去重检查。Fork 真正创建与新版手机界面、第二台物理 PC 验收仍需实测，不以构建成功代替。

## 0.1.4 专项验收

1. 选择电脑 A，打开任务、返回、切后台、杀进程重开，仍选中 A；A 离线或改名不重置，主动取消关注或移除 A 才回到全部。选中 A 时的新建不能默认路由到 B。
2. 两台电脑提供商／目录不同，模型列表不能混用；切换 A 会话下一轮模型和强度，不中断当前轮次，不改变 B、其他会话、账号、审批、沙箱或全局设置。
3. 电脑同时改模型、桥接重启或弹窗过旧时拒绝旧选择；未知模型／强度及无可验证目录必须保守拒绝。
4. 在用户明确选择的空闲纯文字测试会话编辑最新消息，确认 PC 同步撤回本轮并重新生成；文件不会自动还原。原任务运行中、存在追加／附件／自定义权限、目标变化时拒绝，不静默改为另发一条指令。
5. 编辑过程中断网或失败，核对是否只完成撤回，确认不自动重发；未确认结果持久锁定。不会用当前开发聊天做该测试。
6. 仅最终完成回复显示小绿点和“已完成”；中途回复和失败不误标。首页未读完成点到达该会话最新回复后清除，同 ID 不同电脑和不同轮次不串线。
7. 经已配对无线 ADB 覆盖安装，不清空手机数据；核对版本、签名、拉回的 APK 哈希和保留的配对关系。
8. 另一版本 Codex 的 PC 更新桥接后，不因未知版本号或归档哈希锁定；握手通过则正常显示。缺少某个工具或原生方法版本时只拒绝该功能，其他功能继续使用，不能自动降级、转机或放宽权限。
9. 真正无法握手、后端不唯一、会话结构未知时给出具体诊断，不把只读历史伪装为实时控制。派发后的断线／错误仍为未确认，不能误标为可安全重发。
