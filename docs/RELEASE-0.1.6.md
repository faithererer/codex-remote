# 0.1.6 更新说明

- 聊天支持通过系统选图器添加最多 5 张图片，发送前预览或移除；支持只发图片、图文及运行中追加图片。
- 按电脑／会话持久保存图片草稿。发送未确认时保留草稿，不自动重发、不转移到其他电脑。
- 显示用户附件、原生图片查看／生成、工具内嵌图片，以及 AI 回复引用的本地图片；点开可双指缩放、拖动和双击切换大小。
- 图片使用固定证书、原配对凭证和单独的会话图片接口。上传同时校验电脑、实例、会话与手机，校验格式、像素及大小，不提供任意路径读写或远程 URL 代理。
- 保留 0.1.5 的普通局域网／Tailscale 双入口，以及 0.1.4 的模型、编辑、关注和完成标识。

手机同签名覆盖安装 APK；每台 PC 退出旧桥接后覆盖 Windows 便携文件并重开桥接。保留原配对数据，不需要重启 Codex。两端都需更新到 0.1.6 才能使用图片。

新建聊天首条消息仍由原桌面新建工具接收文字，进入聊天后可附图；图片消息的编辑请在电脑完成。图片长边自动缩到最多 2048 像素，动图按静态帧处理，不自动加载外站图片。详细说明见 IMAGES.md。

本次没有对真实聊天发送、追加、编辑或中断测试指令。构建、隔离测试和原桌面协议只读检查通过的范围见 VERIFICATION.md；手机实机图片发送／触控和第二台物理 PC 验收仍待完成。
