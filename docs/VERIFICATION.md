这是实验性预览，不是全部产品验收或安全审计通过声明。

## 已验证

| 类别 | 结果与边界 |
| --- | --- |
| Windows 构建 | .NET 10 自包含 Windows x64 单文件构建成功 |
| Windows 自测 | 30 项隔离自测通过；另有 1 项可选本地快照测试通过，私有快照不发布 |
| 私网接口 | 14 项 HTTPS/WSS 测试通过，使用同一物理 PC 的两个临时身份，不是两台电脑 |

| APK | 发布签名校验通过；实际手机覆盖安装为 0.1.3/versionCode 4，拉回的已安装 APK 哈希与交付物一致 |
| 消息去重 | 原始输入与原生用户回显合成一行；保留独立同文消息、不同轮次和追加指示 |
| 点击与操作锁 | 点击时同步锁定；同一电脑重叠提交拒绝而非排队，不阻塞另一台电脑；未知结果不自动重发 |
| 原桌面状态 | 只读检查成功；原后端未重启，电脑身份和配对设备记录更新前后不变 |
| 多连接 | 一台真实 PC 上的双桥接身份通过手机同时连接与身份隔离检查，仅证明此拓扑 |

## 尚未验收

- 第二台物理 Windows PC 与同一手机同时运行、操作、断线恢复和故障隔离。
- Fork 的实际聊天复制、新 Git 工作树设置，以及设置失败的真实端到端恢复。
- 新建真实任务、完整 Markdown、diff 弹窗和新按钮的完整手机端人工回归。
- 真实命令／文件审批、选择题和桌面与手机同时响应的竞争场景。
- 两台电脑的同名会话／相同会话 ID 故障演练，真实网络切换和不确定结果恢复。
- 锁屏、移动网络、省电、前台服务、通知、强停恢复及长时间多连接稳定性。
- 其他 Codex 桌面版本的兼容性，以及独立安全审计。

已知部分真机无障碍 UI 自动化有等待问题，测试类显式 `@Ignore`，不算通过。
当前版本能在已适配环境试用，不应表述为“全面兼容”或“多 PC 真机验收通过”。
执行手动验收参照 `ACCEPTANCE.md`。

## CI

CI 运行源码敏感信息模式检查、Android debug 构建／JVM 测试／lint，以及 Windows
release 构建／隔离自测。CI 没有 Tailscale 设备、真实聊天、维护者签名私钥或手机配对数据。
因此 CI 成功不能替代上述真机、两台 PC 或安全验收。
