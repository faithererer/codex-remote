# 图片上传与查看

手机和目标电脑的 Windows 桥接都更新到 0.1.6。覆盖更新保留原配对，不需要退出 Codex 或中断任务。

## 手机使用

1. 进入目标电脑的一个聊天，核对顶部的电脑名称／会话标题。
2. 点输入框左侧的图片按钮，在系统选图器里选择图片。Android 10 及以上均有适配，不需要授权整个相册。
3. 输入框上方显示待发缩略图，点图可预览，右上角叉号移除。每条消息最多 5 张；可只发图片，也可配文字。
4. 点击发送。空闲聊天开启一轮，正在运行的聊天通过原桌面追加指示通道接收图片。不会另建模型后端、切换电脑或修改权限。
5. 聊天中的附件、原生图片查看／生成结果、工具返回的内嵌图片，以及 AI Markdown 引用的本地图片会显示缩略图。点开后双指缩放、拖动，双击切换大小。

新建聊天的首条指令目前沿用桌面新建工具的文字输入；进入新聊天后可以附图。编辑带图片的最新消息仍请在电脑完成，以保留原上下文。

## 大小、格式及保存

- 选图后手机自动处理方向、将长边缩到最多 2048 像素并转换为 PNG／JPEG，移除原文件 EXIF 等元数据。原图不修改；动图以静态帧发送／显示。
- 单张传输上限 10 MB，原图读取上限 30 MB。会话图片查看支持 PNG、JPEG、GIF、WebP，最多 3200 万像素。大图超过限制时请在电脑查看。
- 图片发送给这台电脑当前聊天选用的模型；是否能理解图片取决于模型本身的能力。
- 待发图片存于手机应用私有目录，按 hostId／threadId 隔离。发送失败、离线或结果不确定时保留草稿；退出聊天再进入仍可看到。不会离线排队执行。
- Windows 附件保存在当前用户的 `%LOCALAPPDATA%\CodexRemote\images`，随机文件名，不写入项目目录或会话数据库。附件索引通过 DPAPI 保护，图片文件沿用 Windows 当前用户目录的访问保护，不是加密相册。
- 未用于发送的暂存图片在 24 小时后由后续上传触发清理；每个手机待用附件额度 50 MB，电脑附件总额度 1 GB。已用于发送或结果未知的图片保留，避免破坏桌面会话。不要删除正在使用的附件；需要清理旧图时先自行备份相关会话所需文件。

## 连接与限制

所有上传、读取都经过原配对凭证和证书固定校验；上传同时绑定电脑、后端实例、会话和手机。实例改变后需重新确认发送，旧附件不能直接用于新实例。上传图片本身不会执行聊天指令；只有发送操作才进入持久化操作去重流程。网络断开后不会自动重发。

查看接口只接受会话中的图片标识，不接受手机指定的电脑路径，不代理外部 URL，不读取 UNC／网络共享、重解析路径或任意文件。远程网站图片不会自动访问。电脑图片被移动、删除、超限，或不在当前已读取的历史范围内时会提示无法加载，可刷新后点图重试；尚未接入实时状态的历史聊天需先在原桌面打开。

## 回退

退出 Windows 桥接后换回原便携包即可，保留 `%LOCALAPPDATA%\CodexRemote`。旧桥接仍可使用原有文字功能，但不提供图片接口；新手机发送图片时会提示更新桥接。Android 不卸载、不清除数据；系统通常拒绝直接降级 versionCode，需回退时从旧源码以更高版本号和同一签名构建，避免丢失配对。
