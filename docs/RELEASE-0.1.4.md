# 0.1.4 更新说明

## 这次新增

- 输入框上方的模型选择：按目标电脑当前提供商的已配置模型目录，切换本会话下一轮模型及思考强度。当前任务不中断，其他电脑与会话不改变，权限和全局配置不改动。
- 编辑最新消息：修改后明确确认，使用原桌面的原生编辑／撤回／重新生成流程，不是另发一条新指令。运行中、已变更的目标、带追加消息或附件／结构化上下文、自定义权限等无法安全编辑的情形不提交。
- 记住首页所选电脑和任务筛选；返回、切换 App、重开都保留。离线或改名不重置，不把草稿和指令转发到另一台电脑。
- 最终完成回复的小绿点和文字标注；首页新完成的未读任务也有小绿点，到达对应会话的最新回复后清除。不同电脑上的同 ID 会话互不干扰。
- 移除桌面版本号／归档哈希白名单锁定。改为运行时验证原桌面握手、工具参数契约和目标会话状态；某项功能真正不兼容时只拒绝该操作，不影响其他兼容功能。不会换后端、降低权限或自动尝试其他协议版本。

## 更新与回退

Android 同签名覆盖安装，不要先卸载；Windows 退出旧桥接后覆盖便携目录再运行。保留 `%LOCALAPPDATA%/CodexRemote`，无需重新配对。不退出或重启 Codex，不中断桌面任务。无线 ADB 已配对时可用 `adb -s <无线地址> install -r --user 0 <APK>`，不要求插线或启用不安全的 TCP 5555 调试。

另一台电脑如果仍显示“版本未验证，远程控制已锁定”，需要更新那台电脑上的 Windows 桥接；仅更新手机不能移除旧桥接里的版本锁。新桥接会记录每台电脑实际自检的版本，但不会仅因不在旧版本列表而阻止接入。

需回退时，先退出桥接并恢复旧版 Windows 包，仍保留本地身份／配对记录。Android 旧版 versionCode 较低，系统通常拒绝直接降级；不要为了降级卸载应用清除配对，优先使用保留数据的后续修复版本。

## 验证边界

Windows 44 项隔离自测、17 项同 PC 双身份接口测试、Android 62 项 JVM 测试通过。原桌面只读协议／状态检查通过，模型目录检查读到 8 个配置模型。未对正在开发的真实聊天执行切换模型、编辑、Fork 或中断测试；这些测试会影响真实任务，不能用来刷“验收通过”。

仍需用户在合适的空闲聊天实测模型与编辑后的完整行为、第二台物理 PC、其他 Codex 构建、手机新 UI、锁屏与长时间后台监控。现阶段为按功能自检的实验性预览，不是“所有版本已验证”。
