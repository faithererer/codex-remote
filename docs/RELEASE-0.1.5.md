# 0.1.5 更新说明

- 支持普通局域网直连：手机和电脑在同一 Wi-Fi／局域网时不再依赖 Tailscale，外出访问仍保留 Tailscale。
- Windows 自动发现已连接网卡上的 RFC1918 私有 IPv4 和 Tailscale 地址，桥接窗口可选择二维码使用的网络，并复制连接地址；网络地址变化后自动重新检测。
- 手机“我的电脑”增加“修改连接地址”，使用原证书、设备凭证和电脑身份核对成功后才保存。无需删掉电脑重配，关注、草稿及未确认操作保留。
- 同一电脑的两种网络入口共用身份、后端实例、事件和操作去重锁；旧连接迟到的事件／状态会被丢弃，不自动换地址、换电脑或重发指令。
- 网络错误按局域网／Tailscale 分别说明，不再一律要求开启 Tailscale。HTTPS/WSS、扫码电脑确认、证书固定、沙箱及审批继续保留。

两端均需更新到 0.1.5；Android 同签名覆盖安装，Windows 退出旧桥接后覆盖便携文件，保留本地身份目录。无需重启 Codex。

构建及本机验证：47 项 Windows 隔离自测、20 项同 PC 私网 HTTPS/WSS 测试、74 项 Android JVM 测试，以及 Android release/debug、lint 和仪器测试代码编译通过。接口测试实际以局域网地址作为主入口，同时核对 Tailscale 地址上的身份与去重；未执行真实任务指令。

本次手机无线调试未连接，尚未安装新版到真实手机，也未完成无 Tailscale 的手机 Wi-Fi／锁屏、两台物理 PC 或路由器／防火墙端到端验收。签名和构建成功不等于这些场景已验收。使用步骤见 `LAN.md`。
